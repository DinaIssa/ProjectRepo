This diagram explains what happens behind the scenes when a user requests a website (http://facebook.com).

1. **Domain Query:** When the client (browser) enters the address `http://facebook.com`, it sends a domain query to the **DNS** .
2. **Return IP Address:** The DNS resolves the domain name and returns the corresponding **IP Address** back to the browser.
3. **HTTP Request:** The browser uses this IP address to send an **HTTP Request** to the destination **Server**.
4. **HTTP Response:** The Server processes the request and sends back an **HTTP Response** to display it on the client's browser.
